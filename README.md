# PCA / SVD from scratch

NumPy PCA with five solvers, three of them written from scratch (Jacobi SVD,
power iteration, randomized SVD). Exact solvers match scikit-learn to about
1e-12 on the Olivetti faces. The randomized solver is approximate, as expected
on a spectrum that decays slowly.

Figures are generated by `python demo.py` into `assets/`. Timings come from
`python benchmark.py`.
